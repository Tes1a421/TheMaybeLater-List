<p align="center"><strong>The Maybe-Later List</strong></p>

一款常驻 Windows 桌面右侧的轻量待办工具。默认收起为悬浮栏，鼠标移入后自动展开，适合快速记录有截止日期和工作时间要求的事项。

“鸽单”是一个带有自嘲意味的中文双关：事情被“鸽了”，一直拖着没办，于是形成了一张越积越长的清单。英文名采用 **The Maybe-Later List**，表达“先放着，可能晚点再做”最终却一拖再拖的诙谐感。

## 主要功能

- 桌面右侧悬浮、自动展开和收起
- 四类事项：重要紧急、不重要紧急、重要不紧急、不重要不紧急
- 逾期事项自动置顶
- 完成日期、小时/分钟双滚轮和多档提前提醒
- 自定义上班、下班时间
- 仅设置日期时，上班时间提醒，下班后自动逾期
- 勾选后立即变灰并添加删除线，10 分钟后移至已完成
- Windows 系统通知和应用内提醒
- 开机启动、托盘菜单以及隐藏到托盘
- 本地保存数据，不需要账号或服务器

## 文本指令

在事项名称后输入 `#`，井号后的文字会转换为设置，不会保留在事项标题中。

| 输入示例 | 识别结果 |
| --- | --- |
| `提交报告 #急 明天` | 重要紧急，明天完成 |
| `整理资料 #不急 明天` | 不重要不紧急，明天完成 |
| `预约复诊 #后天 上午9点` | 后天 09:00 完成 |
| `取快递 #两小时后` | 当前时间两小时后完成 |
| `续费服务 #下个月` | 下个月同一天完成 |
| `提交材料 #后天下班前10分钟提醒我` | 后天下班前 10 分钟提醒，下班后逾期 |

支持今天、明天、后天、大后天、若干天后、若干周后、下个月、若干个月后、分钟后、小时后以及上午/下午具体时刻等常用表达。

## 下载和安装

请前往仓库的 **Releases** 页面下载：

- `Xiaoyang-Gedan-版本号-x64.exe`：Windows 安装程序
- `Xiaoyang-Gedan-版本号-x64.zip`：免安装便携版，解压后运行 `小羊鸽单.exe`
- `SHA256SUMS.txt`：用于核对下载文件完整性的 SHA-256 校验值

未签名的安装包可能触发 Windows SmartScreen。个人测试时可核对下载来源和文件哈希后，选择“更多信息 → 仍要运行”。不要关闭系统的整体安全防护。

## 本地开发

环境要求：Windows 10/11、Node.js 18 或更高版本。

```powershell
npm install
npm start
```

## 构建 Windows 发布包

```powershell
npm ci
npm run build:win
```

输出位于 `release`：

- `Xiaoyang-Gedan-1.0.0-x64.exe`
- `Xiaoyang-Gedan-1.0.0-x64.zip`

`release` 不提交到 Git。正式二进制文件应上传到 GitHub Releases。

## 数据与隐私

事项和设置保存在本机 Electron 用户数据目录中，不会上传到服务器。应用从旧名称“浮光待办”或“小羊鸽蛋”升级时，会自动迁移原有本地数据。
